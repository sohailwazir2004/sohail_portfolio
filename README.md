# My Portfolio

My personal portfolio website, built with React. It introduces me and shows my education, skills, projects, certifications and a contact form.

**Live site:** https://my-portfolio-three-silk-27.vercel.app

## Features

- Sections for About, Education, Skills, Projects, Certifications, Achievements and Contact
- Dark mode toggle
- Responsive layout for phone and desktop
- Contact form built with React state

## Tech stack

- React (Create React App)
- JavaScript (ES6+), CSS3
- Deployed on Vercel

## Run it locally

```bash
git clone https://github.com/sohailwazir2004/my-portfolio.git
cd my-portfolio
npm install
npm start
```

Then open http://localhost:3000.

To make a production build, run `npm run build`.

## Project structure

```
public/        # static files
src/App.js     # page sections and data (projects, skills, certifications)
src/App.css    # styles
```
